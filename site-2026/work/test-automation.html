Case study 06 · Tithely · Quality

Test automation, started from scratch.

Today I work as a developer and SDET at Tithely, owning integrations and building automated tests with Playwright. A couple of test projects already existed, but I started a new one from zero, and this time with AI writing most of the code while I make the decisions.

Role
Developer · SDET · lead
Era
AI-assisted
Stack
Playwright · Docker · CI
Also
Integrations · Jira/Xray
Context

Testing existed. Nobody could see it.

The team mixes in-house developers with contract SDETs. They did QA, but nothing in reporting showed it, and critical flows like sign-in relied mostly on people clicking through by hand.

Diagnosis

The tool was there. The setup was broken.

The org already had Xray for test management. Looking closely, I found why it showed nothing:

✕

Tests with no type

Test issues were created with no Test Type, so they never counted as real tests in coverage reports.

✕

Executions linked to nothing

Test Executions were logged with no linked Tests, so finished QA runs proved nothing to anyone reading the board.

What I built
  1. A new automation project, from zeroStarted a fresh Playwright project instead of patching the existing ones, with coverage for the QA hub and the sign-in flows.
  2. Fix Xray adoptionSet proper Test Types and linked executions to their tests, so manual QA shows up in coverage and reporting.
  3. Containerized CI/CDSet up a containerized environment so tests run the same way locally and in the pipeline, and tuned CI timeouts so slow is not mistaken for broken.
  4. GitHub ActionsWorkflows that pull images from different projects and codebases, spin them up together in containers, and run the test suites automatically.
  5. Own the integrationsBeyond tests, I take care of several of the product's integrations.
  6. Team status toolingWrote a /team-status Claude Code command that gathers tickets, story points, blockers and risk per person into one view.
AI era

Same judgment, different keyboard.

Most projects on this site I wrote by hand. This one is different: the code is generated with AI. My job moved to deciding what to test, shaping the architecture, and reviewing what comes out. The years of handcrafting are exactly what make that review worth something.
