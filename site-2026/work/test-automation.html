Case study 03 · Church-tech SaaS

Starting a test automation project from scratch

Today I lead a 15-person outsourced team, and I also work on integrations and automated tests myself. A couple of test projects already existed, but I decided to start a new one from zero. This one is AI-era: most of the code is generated with AI, and my job is the decisions and the review.

Industry
Church-tech SaaS
Role
Lead · developer · SDET
Team
Leading a 15-person outsourced team
Stack
Playwright · Docker · GitHub Actions · Jira/Xray

My role and responsibilities

  • Lead a 15-person outsourced team, with near-daily visibility on tickets, blockers and risk per person.
  • Own several of the product's integrations.
  • Drive QA process and test infrastructure, instead of leaving it to someone else.

Key decisions

  • Start a new project instead of patching the old ones. A clean base for Playwright end-to-end coverage of the QA hub and sign-in flows.
  • Fix test management before adding more tests. Xray existed but was misconfigured: tests had no type and executions were linked to nothing, so finished QA proved nothing in reports.
  • Containerize everything. Tests should run the same way locally and in CI.
  • Let AI write, keep humans deciding. AI generates most of the code; I decide what to test, shape the architecture and review the output.

What we built

  • Playwright E2E suite. For the QA hub and the sign-in flows.
  • GitHub Actions workflows. That pull images from different projects and codebases, spin them up together in containers, and run the tests automatically.
  • Visible manual QA. Proper test types and linked executions, so manual testing shows up in coverage.
  • Team status tooling. A /team-status Claude Code command that gathers tickets, story points, blockers and risk per person into one view.

The hard part

Getting a mixed, outsourced team to treat quality as shared work, and making that work visible to people who only read reports.

What I learned

AI writes the code; someone still has to know what good looks like. Years of writing everything by hand are what make the review worth something.
