Case study 02 · Tithely · Media

One media library, everywhere.

Media serves images and visual content to the churches that use Tithely, and works as storage for their own files. Its most-used piece isn't the site: it's an NPM package that drops the whole library into other Tithely products.

Product
Multimedia library
Users
Tithely client organizations
Key piece
Embeddable NPM package
Reach
Used across many products
Context

Great content, in the wrong place.

Tithely creates images and visual content for churches, and churches have their own media too. Media is where both live: a library of Tithely-made content plus storage for each organization's files. But people need that content while working in other Tithely products, not in a separate tab.

The package

Bring the library to the user.

  1. Media platformWorked on Media itself: the landing page with all its content, and the library that serves images and multimedia to client organizations.
  2. Storage for organizationsOrganizations keep their own media there, next to the content Tithely creates for them.
  3. The NPM packageAn installable package that opens a modal inside any Tithely product: the user signs in, browses their Media account and Tithely's content, and uses it right there.
Why it matters

Simple product, huge reach.

Media on its own is fairly simple. The package is what made it important: it's used in a lot of places across Tithely, so one well-built component gives every product the same media experience without each team rebuilding it.
